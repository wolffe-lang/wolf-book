# ch31 — tells audit (bs14, lane C)

- severity counts: charter 1 · tell 4 · noted 3
- em-dashes in prose: 15 raw; 8 rhetorical after excluding 6 `### M<n> —` heading titles and the epigraph attribution dash; 1064 prose words → 7.5 per 1000 (raw 14.1)
- negation-family count: 5 (three of them the same emphasis-by-negation fragment)
- banned-vocabulary hits: none
- verdict: Close to the K&R register — terse, present-tense, code-first — but it leans on one move, the emphasis-by-negation fragment ("Not any — every."), three times in eleven hundred words, and that repetition is the tell.

## Findings

- [10-12] «Not "mostly" and not "with a little searching" — every construct in the program below appears in a chapter you have read» — negation family (emphasis-by-negation windup); severity: tell; suggestion: cut the windup — "Every construct in the program below appears in a chapter you have read" already carries the claim.
- [14-15] «the only way to find out whether it is true is for you to write the program and for us to stay quiet» — "us" is the authors alone, and TONE §1 reserves "we" for author-and-reader moving together (author alone is "I", preface only); severity: charter; suggestion: "for you to write the program while the book stays quiet."
- [60-61] «A line matches when it contains **every** term. Not any — every.» — negation fragment plus bold-for-emphasis in prose; severity: tell; suggestion: "A line matches when it contains every term on the command line" — one sentence, no bold, no echo.
- [82-83] «This is not a suggestion about how to be fast; it is part of the specification» — negation family ("not X; it is Y"); severity: tell; suggestion: "This is part of the specification, because it is what the chapter is for."
- [85-86] «The four report lines are identical on every run of the same query against the same den. Not usually identical. Identical.» — third emphasis-by-negation fragment in the chapter; severity: tell; suggestion: keep one flat sentence — "identical on every run, without qualifier" — and let it stand alone once, not three times per chapter.
- [6-7] «a specification, six checkpoints, and no walkthrough» — rule-of-three shape, but the three items are the chapter's actual three properties and the list is real; severity: noted (context defends; recorded for density).
- [26-29] «**The den.** … **The query.** …» (also [54], [63], [76], [80], [85]) — bold run-in labels; these are structural headers for the specification's parts, not emphasis sprinkle; severity: noted (context defends).
- [162-165] «Four is a constant in this program in every sense — a constant in the specification and a constant on the page — and a version that tries to compute it is a version that stops compiling» — em-dash pair where commas or parentheses serve; severity: noted (density; the sentence survives the swap unchanged).
