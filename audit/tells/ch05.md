## Findings

### Charter (tense discipline — the chapter's dominant defect)

- [183-184] «That leaves `Set`, and here the book has to be honest: the pinned interpreter has not got one.» — deferral prose + pin apparatus ("the pinned interpreter" is banned from reader text by TONE.md §Tense verbatim); severity: charter; state scope instead: "Part 1 uses a `List` and a linear scan where a set belongs" — or the section waits for the surface.
- [186-209] «Exit 4 is the interpreter declining the program rather than running it, and the message blames the element type rather than the missing container.» — scaffold output taught: an `unsupported` refusal printed as a checked sample and explicated, which TONE.md forbids ("scaffold output is not product output"); severity: charter; drop the refusal sample and teach the List-scan idiom without the absence on stage.
- [251-252] «None of the combinators exist yet — not `sorted_by`, not `take`, not `map`, `filter`, or `sum`.» — deferral prose ("exist yet") + negation anaphora; severity: charter; state the subset as scope: "Part 1's std has one combinator, `count()`; this section builds the loop the chain desugars to."
- [258-261] «So the section's promise arrives in the honest order. Instead of writing the chain and then desugaring it for understanding, we write the desugaring because it runs» — workaround narrated as concession; fails TONE.md's survive-the-landing test ("because it runs" dates the passage); severity: charter; teach loop-then-chain as pedagogy: "First the loop, because the loop is what the chain means."
- [419-424] «When this chapter was first true, there were no traits — the `fn(T, T) -> bool` parameter stood in for a comparison trait that had not landed» — edition/schedule narration ("first true", "had not landed", "has landed since"); severity: charter; keep only the pedagogy: "The function parameter stays: what `best` may do with a `T` is what you hand it."
- [552-554] «Section 5.3 promised a comparison trait "that lands with the trait system," and for several printings that sentence was a schedule. It is now a fact.» — printing/schedule meta-narration + "was X. It is now Y." cadence; severity: charter; open on the material: "A trait names a capability; an `impl` says a type has it."
- [598-600] «The method sugar `n.text()` does not reach primitives yet; the compiler refuses it by name, and this book teaches the spelling that works today rather than the one scheduled to.» — deferral prose ("yet", "today", "scheduled to"); severity: charter; teach the qualified form as the form: "On a primitive the call spells the trait's name: `Text.text(n)`."
- [675-677] «A `dyn` crosses a call today; carrying one inside a container is the compiler being honest about its schedule again, and the refusal names itself.» — deferral prose + honest-motif; severity: charter; if container-`dyn` is D-numbered scope, state it as scope; otherwise the sentence waits.
- [679-683] «`==` and `<=>` do not dispatch through `Eq` or `Ord` at this printing. The design that bridges them is decided; the code that does it has not landed. Until it does, comparison traits are called the way every trait here is called — by name.» — the full deferral family in three sentences ("at this printing", "has not landed", "Until it does"); severity: charter; cut to fact: "Comparison operators do not dispatch through traits; comparison traits are called by name."
