## Findings

- [3–5] «A module is a directory in your project. A *package* is a
  directory somebody else wrote, and the difference is not technical — it
  is that you did not read it.» — negation family + em-dash where a colon
  serves; the epigram earns its content but opens a chapter-long pattern;
  severity: tell; suggestion: "…somebody else wrote. The difference is
  that you did not read it."
- [58–59] «There is no code. Not a script, not an expression, not a
  string that gets interpolated» — negation anaphora in rule-of-three
  rhythm; severity: tell; suggestion: "There is no code: the values are
  strings, integers, bare words, lists, and maps, and that is the entire
  grammar."
- [61–63] «**reading a manifest tells you everything a package does to
  the machine that builds it, because a manifest cannot ask for anything
  to happen.**» — bold-for-emphasis on a full sentence in running prose
  (bold-sprinkle); recurs at ch24 L10 — lane-level pattern; severity:
  tell; suggestion: drop the bold; the sentence carries itself.
- [66–71] «owned rather than claimed … a manifest edit rather than a
  search-and-replace» — first two of the chapter's five "X rather than Y"
  contrasts (also L212, L241, L245); as a default frame it is the
  negation family in formal wear; severity: tell; suggestion: vary the
  frame — state the positive fact and let one contrast stand per section.
- [84] «a moving target is not a dependency, it is a subscription.» —

  recorded for density; severity: noted; suggestion: keep, or "a moving
