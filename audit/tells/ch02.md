# ch02 — tells audit (bs14, lane A)

**Counts by severity:** charter 1 · tell 7 · noted 12 — 20 rows.
**Em-dashes (prose only, fences and ledger stripped):** 35 in 2277 prose
words = **15.4 per 1000** — second-highest in the lane; the recurring
shapes are the dash-pair-around-a-list and the trailing "— which is
§N.M's business" cross-reference.
**Negation family:** 12 instances (lines 6–8, 72–75, 82–83, 218–220,
222, 224–225, 231–232, 364, 367–368, 376–377, 381–382, plus the
"not only a name" half-form at 75), of which the §2.3 opening (198–229)
carries sanctioned TONE §3.3 lineage — see Defended.
**Banned vocabulary:** none (verified by eye and grep; no
delve/pivotal/crucial/robust hits, zero "simply/just/easy/of course",
no "serves as/stands as" copulas).
**Verdict:** vocabulary-clean and often genuinely at register (§2.5's
cost-model prose is the book at its best), but §2.4 runs a three-fold
"a char is not X" negation architecture on top of one full
tense-discipline breach, and the em-dash is this chapter's default
connective.

## Findings

### Charter

- [356-361] «These are compiler-lane runs, and this section says so the
  way this book says such things: the interpreter at this printing's
  pin does not read the type yet — under `lupin`, `'` begins no token
  and `chars()` answers `unsupported` by name — so until the
  interpreter's char work lands, the programs of this section run under
  `wolf run` and nowhere else.» — the full deferral family in one
  sentence ("at this printing's pin", "does not … yet", "until … lands")
  plus pin apparatus in reader text, which TONE's tense discipline bans
  verbatim; severity: charter; state the lane as fact: "The programs of
  this section run under `wolf run`" — the why belongs in the ledger,
  not the page.

### Tell

- [72-75] «The interpolation is not a printf-style call with the format
  string on one side and the arguments on the other. There is one place
  to look, the expression sits where its value lands, and the pair does
  not drift apart during a refactor.» — negation-family opener resolved
  by a rule-of-three; severity: tell; "Interpolation keeps the
  expression where its value lands, so the pair cannot drift apart
  during a refactor."
- [226-229] «iterators that spell their unit — `bytes()`, `chars()`,
  `words()`, `lines()`, each one named for what it hands you, and §2.4
  walks them — and it declines to hand you an `s[i]` whose meaning
  changes with the alphabet.» — dash-pair enclosing a list (the
  notation.md template shape) with a cross-reference stuffed inside the
  pair, on a sentence already three clauses deep; severity: tell;
  parenthesize the list, move "§2.4 walks them" to its own sentence.
- [231-233] «Checked is the load-bearing word. A range that runs off the
  end is a fault, not a surprise value and not undefined behavior — you
  saw one in §1.5.» — self-signposting ("load-bearing word") + double
  negation + dash-appended cross-reference in one breath; severity:
  tell; "A range that runs off the end is a fault (§1.5 showed one)."
- [257-265] «Python bought that with a representation it chooses per
  string and a cost model you cannot see; wolf keeps one representation,
  tells you the unit, and refuses the operation whose answer depends on
  which definition of "character" you had in mind. Neither position is
  free. Python's is friendlier to a first program; wolf's is friendlier
  to a program whose costs you have to predict» — balanced-antithesis
  mirror + rule-of-three + the "Neither X is free" formula (ch01 line
  210 has "Neither answer is free" — a lane echo); severity: tell; keep
  the contrast, break the mirror: one sentence on what Python chose, one
  on what wolf chose, stop.
- [363-382] «Three decisions are visible in that output. Six bytes, five
  chars: a `char` is *not a byte* — … because a `char` is *not an
  integer* either … a `char` is *not a grapheme* — not "what the reader
  sees".» — negation anaphora as section architecture: three definitions
  each delivered negation-first with italic stress, spanning three
  paragraphs; severity: tell; define affirmatively ("a `char` is one
  Unicode scalar — wider than a byte, narrower than a glyph, distinct
  from an integer") and let one contrast survive.
- [374] «a `char` no string could encode would be a lie wearing a type»
  — wardrobe-metaphor flourish (ch08 line 13 has "the same problem
  wearing different clothes" — the same clothes-metaphor tic);
  severity: tell; "a `char` no string could encode."
- [488-490] «there is no format string left to parse, no argument list
  to walk, and no way for the two to disagree about how many `%s` you
  wrote» — "no X, no Y, no Z" anaphora triplet (lane pattern N1);
  severity: tell; "there is no format string left at runtime, so the
  two cannot disagree."
