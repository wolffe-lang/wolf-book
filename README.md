# The Wolf Book

The official wolf language text. Campaign bc00 (toolchain + voice) opens
after the compiler's M1 milestone; until then this scaffold holds the
repo's place in the project roster.

Prose license: TBD at bc00 (CC BY 4.0 proposed). Code samples:
MIT or Apache-2.0, matching the language.

The book's principles live in [`principles/`](principles/): TONE.md
(the voice, by rule and demonstration), TOC.md (the full table of
contents, section-numbered), EXERCISES.md (numbering, taxonomy,
solutions policy, and the chapter 1–6 exemplar batch with runnable
programs under `principles/exercises/`), DESIGN.md (typography, the
single-source highlight contract, navigation, and the multi-format
pipeline), and INTERACTIVITY.md (the widget doctrine and the *Dear
Computer* catalog). Every chapter sprint writes to these documents;
bs00 implements what DESIGN.md and INTERACTIVITY.md contract.
